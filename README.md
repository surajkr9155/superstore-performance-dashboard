# 📊 Superstore Performance Dashboard

An interactive **Excel-based Business Intelligence Dashboard** designed to analyze Superstore sales performance, profitability, orders, customers, products, regions, and shipping trends.

## 🚀 Project Overview

This project transforms Superstore sales data into an interactive dashboard that helps users understand business performance through key metrics, visualizations, and filters.

The dashboard provides a clear view of:

* 💰 Sales Performance
* 📈 Profitability
* 🛒 Orders & Quantity
* 👥 Customer Segments
* 📦 Product Categories
* 🌎 Regional Performance
* 🚚 Shipping Analysis
* 🏷️ Discount Impact
* 📅 Time-based Sales Trends

## 📌 Key KPIs

The dashboard focuses on important business metrics such as:

* **Total Sales**
* **Total Profit**
* **Total Orders**
* **Total Quantity Sold**
* **Average Order Value**
* **Profit Margin**

## 🎯 Dashboard Features

* Interactive filters and slicers
* Sales and profit trend analysis
* Category and sub-category performance
* Regional sales comparison
* Customer segment analysis
* Shipping mode analysis
* Discount and profitability analysis
* Easy-to-understand KPI cards
* Interactive charts and visualizations
